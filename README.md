## 💻 Getting Started

Follow these steps to run the frontend project on your local machine.

### Prerequisites

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/balvantkushwaha/shopping_web_app_frontend.git
```

**2. Navigate to the project folder**

```bash
cd shopping_web_app_frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.
